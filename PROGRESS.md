## Git-теги

Теги `stage-N` создаются локально после каждого этапа. Прокси окружения не пропускает отправку тегов (обрыв соединения), поэтому в удалённом репозитории этапы видны по сообщениям коммитов «Stage N: …».

## Как продолжить

1. `pnpm install`
2. `pnpm test && pnpm build:web && pnpm smoke`
3. `pnpm build:apk -- --stage N` (нужны пакеты Ubuntu `android-sdk android-sdk-platform-23 dalvik-exchange`)
4. Взять первый этап со статусом не «готов».
