# Решения

- **Только Android.** Так сказал владелец проекта. Electron/.exe в этой итерации не собирается, а клиент остаётся веб-кодом, чтобы ПК-обёртку можно было добавить позже.
- **Без Capacitor/Gradle.** `dl.google.com` (Google Maven и Android SDK) закрыт сетевой политикой окружения, поэтому AGP и Capacitor не собираются. Вместо них используется Android SDK из пакетов Ubuntu (`android-sdk`, `android-sdk-platform-23`, `dalvik-exchange`) и собственная Java-оболочка с WebView, которая повторяет то, что дал бы Capacitor (раздача ассетов с https-origin, JS-мост).
- **compileSdk 23, targetSdk 33, minSdk 24.** Из доступных офлайн платформ есть только android.jar API 23. Более новые API вызываются через рефлексию. Значение targetSdk 33 позволяет устанавливать APK на Android 14+ без предупреждений о старом приложении.
- **Собственный WebGL2-рендерер вместо PixiJS.** Мир рисуется одной текстурой (1 пиксель = 1 клетка) с шейдером затенения, освещения и слоёв, а существа рисуются инстансингом. Это быстрее и проще, чем 1M спрайтов-тайлов в Pixi.
- **Процедурные ассеты.** kenney.nl, opengameart.org, freesound и другие сайты закрыты сетевой политикой. Спрайты, тайлы, иконки и звуки генерируются кодом, а загрузчик подхватывает файлы из `/assets` по именам, если их положить.
- **Тик 12 Гц.** Это середина диапазона 10–20: достаточно для плавной интерполяции и экономно на телефоне.
- **ГПСЧ sfc32.** Быстрый, 128 бит состояния, легко сериализуется.
- **Без SharedArrayBuffer.** WebView без cross-origin isolation его не даёт, поэтому всегда используются передаваемые ArrayBuffer (двойной буфер).
- **Вещества и огонь — на уровне клеток, без частиц.** Это дёшево и детерминированно.
- **Ключ подписи** лежит в `tools/signing/debug.keystore` (пароль `android`). Он отладочный и общий для всех этапов. Релизный ключ этапа 12 создаётся отдельно (`tools/signing/release.keystore`) и в реальном проекте должен храниться вне репозитория.
- **AAB собирается вручную.** bundletool недоступен (Google Maven закрыт, в npm только обёртка без jar). AAB собирается так: `aapt2 link --proto-format`, затем архив `base/{manifest,dex,res,assets,resources.pb}` + `BundleConfig.pb`, подпись jarsigner. Структура соответствует формату bundletool 1.15.6, но валидация bundletool не проводилась. Перед загрузкой в Google Play нужно прогнать `bundletool validate` или пересобрать через Gradle.
- **Релизный ключ не в репозитории.** `tools/signing/release.keystore` создаётся при первой релизной сборке и игнорируется git. Пароль берётся из `SOTV_RELEASE_PASS`, по умолчанию `sotvorenie-release`. Для публикации нужен собственный ключ загрузки с надёжным паролем.
- **versionName релиза** — `1.0.0`, у этапных сборок — `1.0.0-stage12`. versionCode общий (stage*100+patch+1), поэтому релиз и отладочная сборка одного этапа не обновляют друг друга: у них разные ключи подписи.
- **Сохранения v2.** Добавлены флаг «спокойной» воды и законы. Сохранения v1 мигрируют автоматически, а файл из будущей версии отклоняется с понятной ошибкой.
- **Адаптивное качество.** В режиме «авто» при FPS ниже min(24, 75 % цели) дольше 6 с качество понижается на ступень (до двух ступеней: разрешение, bloom, частицы). Если FPS держится выше 90 % цели 45 с, ступень возвращается. Ручной выбор качества отключает автоподстройку.
- **Журнал сбоев локальный.** Ошибки JS, worker и Java пишутся в локальное хранилище и показываются в «Об игре». Ничего не отправляется в сеть.
- **База бенчмарка обновляется на каждом этапе.** Если этап намеренно добавляет системы, после оптимизации база пересчитывается (`pnpm bench -- --update`). Дальнейшие изменения внутри этапа сравниваются с ней, допуск 15 %. Абсолютный бюджет тика (8 мс) проверяется всегда.
- **Детерминизм с учётом ввода.** Прямоугольник камеры влияет на частоту «раздумий» ИИ (в кадре чаще), а позже и на выбор мест возрождения видов. Он приходит в worker между тиками, как команда. Поэтому мир детерминирован при одинаковом сиде и одинаковой последовательности ввода, включая камеру. Тесты идут без камеры.
- **Блуждание и преследование по прямой.** Если прямая (Брезенхем) до цели проходима, A* не вызывается. Это снизило число поисков пути в 10–20 раз.
- **Кэш грубой сетки A* по версии чанка.** Кэш инвалидируется счётчиком изменений чанка, а не по времени, поэтому результат не зависит от того, когда считался путь, и сохранение/загрузка не ломают детерминизм. Пути существ сохраняются в файл.
- **Календарь.** День — 180 тиков (15 с при 1×), сезон — 2 дня, год — 8 дней (2 мин при 1×, 15 с при 8×). Так поколения сменяются за разумное время.
- **Ассеты CC0 из зеркал на GitHub (v1.1.0).** Сайты с ассетами закрыты сетью окружения, но GitHub доступен. Звуки взяты из https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds и https://github.com/iwenzhou/kenney, спрайты меню — из https://github.com/dfkeenan/MicroRogue. Лицензия каждого набора проверена по файлу лицензии в репозитории. Процедурный синтез оставлен запасным вариантом.
- **Музыка через `<audio>`, а не через декодирование в память.** Трёхминутный трек в виде AudioBuffer занимает ~50 МБ, поэтому треки проигрываются потоково через MediaElementSource. Android-оболочка отвечает на Range-запросы для аудио. Если трек не загрузится, включается генеративная музыка.
- **Игровой мир остаётся процедурным.** Подходящих наборов 8×8 со стадиями роста растений, эпохами построек и кадрами анимации существ в свободном доступе не нашлось; смешение стилей выглядело бы хуже. Спрайты Kenney используются только в фоне меню.
- **versionCode** с версии 1.x: stage*100 + minor*10 + patch + 1 (1.1.0 → 1211), чтобы новая версия ставилась поверх 1.0.0.
