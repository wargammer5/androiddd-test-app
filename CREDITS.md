# Авторы и лицензии

Файл создаётся командой `pnpm credits` из `packages/client/src/credits.ts`.

| Ресурс | Автор | Лицензия | Ссылка |
|---|---|---|---|
| World graphics, tiles, creature sprites | Procedurally generated by the game code | Project license |  |
| Menu sprites (Micro Roguelike) | Kenney (kenney.nl); edits by Daniel Keenan | CC0 1.0; edits MIT | https://kenney.nl/assets/micro-roguelike |
| UI, impact sounds, music jingles, RPG audio | Kenney (kenney.nl) | CC0 1.0 | https://kenney.nl/assets |
| Sound effects (100 CC0 SFX 1–2, bang, water, breaking, RPG, creature packs) | rubberduck | CC0 1.0 | https://opengameart.org/content/cc0-audio-uploader-rubberduck |
| Music: Ambient 1–2, Theme 1 | Maximiliano Stradex | CC0 1.0 | https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds |
| Music: Chronos, BeatOne, Goodnightmare, MeditatingBeat (fvi) | Team Forbidden / Warfork | CC0 1.0 | https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds |
| Generative music and fallback sounds | Synthesized at runtime with Web Audio | Project license |  |
| Preact | Jason Miller and contributors | MIT | https://preactjs.com |
| fflate | 101arrowz | MIT | https://github.com/101arrowz/fflate |
| Zod | Colin McDonnell | MIT | https://zod.dev |

Пофайловый список звуков с источниками: `packages/client/public/assets/audio/LICENSES.txt`. Спрайты меню: `packages/client/public/assets/sprites/LICENSES.txt`.

Звуки пересобираются скриптом `tools/assets/import-audio.mjs` из зеркал на GitHub: https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds и https://github.com/iwenzhou/kenney. Свой звук можно подключить, положив .ogg в `packages/client/public/assets/audio/` и прописав путь в `manifest.json`.
