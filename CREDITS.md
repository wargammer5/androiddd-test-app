# Авторы и лицензии

Файл создаётся командой `pnpm credits` из `packages/client/src/credits.ts`.

| Ресурс | Автор | Лицензия | Ссылка |
|---|---|---|---|
| Graphics, tiles, sprites | Procedurally generated by the game code | Project license |  |
| Sounds and music | Synthesized at runtime with Web Audio | Project license |  |
| Preact | Jason Miller and contributors | MIT | https://preactjs.com |
| fflate | 101arrowz | MIT | https://github.com/101arrowz/fflate |
| Zod | Colin McDonnell | MIT | https://zod.dev |

Свои ассеты можно положить в `packages/client/public/assets/{sprites,sfx,music}`: загрузчик подхватывает их по именам. После этого добавьте запись в `credits.ts`.
