# Сотворение

Песочница «симулятор бога» для Android. Вид сверху, пиксельный мир, в котором сами по себе живут существа, растут города, возникают королевства, языки и религии, начинаются войны и союзы. Вы — бог: меняете рельеф, разливаете воду и лаву, насылаете бури и чудовищ, благословляете и караете.

Игра работает полностью офлайн. Интерфейс на русском и английском.

*A god-sim sandbox for Android: shape the land, watch creatures build cities, kingdoms, cultures and religions, then bless or destroy them. Offline, Russian and English UI.*

## Что есть в игре

- **Мир** до 1024×1024 клеток: биомы, высоты, реки и моря, сезоны, погода, смена дня и ночи.
- **Вещества:** вода, лава, кислота, снег, лёд, огонь и температура. Лава застывает в камень, лес горит и выгорает.
- **18 видов существ** с 36 чертами характера. Существа сами ищут еду, строят, воюют и размножаются.
- **Города** с экономикой, профессиями, постройками, технологиями и эпохами.
- **Королевства:** правители и наследование, флаги, колонизация суши и моря, восстания.
- **Дипломатия:** войны с осадами, союзы, предательства, дань, кланы, заговоры, торговые пути.
- **Культуры, языки и религии:** распространяются, смешиваются и раскалываются.
- **~75 божественных сил**, законы мира, эпохи и случайные события.
- **Летопись, статистика** с графиками, 9 слоёв карты, скриншоты и таймлапс.
- **Звук и музыка** синтезируются в игре и подстраиваются под происходящее. Освещение от огня и лавы, частицы.
- **Сохранения** с экспортом и импортом файла.

## Для разработчиков

Монорепозиторий на pnpm:

```
packages/sim       ядро симуляции на TypeScript, без DOM
packages/content   игровые данные (JSON) и схемы zod
packages/client    WebGL2-рендер, интерфейс на Preact, звук
apps/android       Java-оболочка с WebView
tools              сборка и проверка APK, бенчмарк
dist/stage-N       готовые сборки по этапам
```

Нужны Node.js 22, pnpm 10 и, для сборки APK, пакеты Ubuntu `android-sdk android-sdk-platform-23 dalvik-exchange`.

```bash
pnpm install
pnpm test            # модульные тесты
pnpm build:web       # сборка клиента
pnpm smoke           # сквозные тесты в Chromium
pnpm bench           # бенчмарк симуляции
pnpm build:apk       # отладочный APK в out/
pnpm verify:apk      # проверка подписи и манифеста
node tools/android/build-apk.mjs --release --aab   # релизный APK и AAB
```
